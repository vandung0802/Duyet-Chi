📥 Nhập hợp đồng từ Excel

File mẫu 1 sheet: cột đầu "Loại dòng" (Hợp đồng / Phụ lục / Tạm ứng / Thanh toán / Bảo lãnh / Hoàn trả / Kế hoạch), mỗi dòng ghi Công ty + Số hợp đồng. Chọn file → xem trước → xác nhận mới ghi. Dòng trùng → cập nhật, không tạo đôi.
